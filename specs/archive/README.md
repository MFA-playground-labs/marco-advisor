# Spec Archive

Archived specs remain version controlled for product and implementation history, but they are not active implementation targets.

## Archive Policy

- Active specs live in `specs/features/` or the page-specific `specs/pages/**` folders.
- Implemented, superseded, deferred, or retired feature specs move here.
- Active README files should list only current specs and link here separately for history.
- When a spec is archived, update its `Status:` line and add it to the index below.
